# Data

`cleaned_dataset.csv` is the cleaned dataset exported by the original ADS1001 course notebook.

The original notebook loaded 19,990 rows and applied median/mode imputation, duplicate removal, removal of `completion_year`, and basic numerical range checks before exporting 18,299 rows.

The original notebook did not record a public source URL for the dataset, so this repository intentionally does not provide an unverified source link.

The portfolio notebook does not overwrite this file. A separate in-memory modelling subset is created for robust analysis.
